Input and Output

How to show information to the user with print(), and how to ask the user for information with input().

01 · The Big Picture

Talking to the user

Every program needs to communicate. Output is how your program shows information to the user — usually with print(). Input is how your program asks the user for information — usually with input().

Together, these two functions let you build programs that actually feel interactive, instead of just running silently in the background.

overview.py
name = input("What's your name? ") # input print("Hello,", name) # output
▸What's your name? Alex
▸Hello, Alex

02 · Output

Showing things with print()

The print() function displays whatever you pass it on the screen. You can print text, numbers, variables — or several of them at once, separated by commas.

print_basics.py
age = 20 city = "Bangalore" print("Hello, World!") print(age) print("Age:", age, "| City:", city)
▸Hello, World!
▸20
▸Age: 20 | City: Bangalore

Notice that when you print multiple things separated by commas, Python automatically adds a space between them.

03 · Formatting Output

sep, end, and f-strings

print() has two handy keyword arguments: sep changes what goes between values, and end changes what's printed after the last value (it's a newline by default).

sep_end.py
print("2026", "07", "07", sep="-") print("Loading", end="...") print("done")
▸2026-07-07
▸Loading...done

Example — f-strings make combining text and variables much cleaner

f_strings.py
name = "Alex" age = 20 print(f"{name} is {age} years old.")
▸Alex is 20 years old.

04 · Input

Asking the user with input()

The input() function pauses your program, shows a prompt, and waits for the user to type something and press Enter. Whatever they type is returned as a value you can store in a variable.

input_basics.py
favorite_food = input("What's your favorite food? ") print("Nice, I like", favorite_food, "too!")
▸What's your favorite food? pizza
▸Nice, I like pizza too!

Always pauses

Your program stops right there and waits until the user presses Enter.

Prompt is optional

input("Enter name: ") shows a message; plain input() shows nothing.

Always returns text

Whatever the user types comes back as a string — even if they type numbers.

Store it right away

Save the result in a variable so you can use it later in your program.

05 · A Quick Note

input() and numbers

Since input() always gives you back a string, doing math on it directly won't work the way you'd expect.

not_a_number.py
age = input("How old are you? ") print(age + 1)
▸How old are you? 20
▸TypeError: can only concatenate str (not "int") to str

For now, just know that wrapping the input in int() tells Python to treat it as a whole number instead of text — we'll cover type conversion properly in a later lesson.

a_number.py
age = int(input("How old are you? ")) print(age + 1)
▸How old are you? 20
▸21

06 · Quick Summary

Before you move on

✓

print() is how your program shows output to the user.

✓

Use sep and end to control how print() formats multiple values.

✓

f-strings — like f"{name}" — are a clean way to mix text and variables.

✓

input() pauses your program and asks the user for information.

✓

input() always returns a string — wrap it in int() if you need a number, for now.
