01 · The Basics

What is a variable?

A variable is a name that points to a value stored in memory. Instead of writing the same value over and over, you give it a label — and reuse that label anywhere in your code.

Think of it like a labelled box: the box holds something, and the label is how you find it again.

variables.py
name = "Alex" age = 20 is_student = True print(name, age, is_student)
▸Alex 20 True

02 · Assignment

Creating a variable

Python doesn't need a special keyword to create a variable. You just pick a name, use a single equals sign =, and give it a value. This is called assignment.

assignment.py
# name = value city = "Bangalore" score = 95

Example — assigning multiple variables in one line

multi_assign.py
x, y, z = 1, 2, 3 print(x, y, z)
▸1 2 3

03 · Naming Rules

What can you call a variable?

Python has a few strict rules, plus some conventions most Python code follows.

Start with a letter or _

Names must begin with a letter (a–z, A–Z) or an underscore — never a number.

Letters, numbers, underscores

After the first character, you can use letters, digits, and underscores freely.

Case-sensitive

age, Age, and AGE are three completely different variables.

No reserved words

You can't use Python keywords like print, if, or class as a name.

Not allowed

2cool, my-name, class — numbers first, hyphens, and keywords all break the rule.

Convention: snake_case

Most Python code uses lowercase words separated by underscores, like first_name.

04 · Dynamic Typing

Variables don't need a type

Unlike some languages, you never declare a variable's type in Python. It figures out the type automatically from the value you assign — this is called dynamic typing.

Example — a variable can even change type later

dynamic.py
value = 10 print(type(value)) value = "now I'm text" print(type(value))
▸<class 'int'>
▸<class 'str'>

05 · Reassignment

Changing a variable's value

Variables aren't locked in — you can assign a new value to the same name whenever you want. The old value is simply replaced.

reassign.py
score = 50 print("Before:", score) score = 80 print("After:", score)
▸Before: 50
▸After: 80
