01 · The Big Picture

Every value has a type

In Python, every single value you work with — a number, a word, a list of names — belongs to a data type. The type tells Python what kind of value it is, what operations make sense on it, and how much memory to use.

Python groups its built-in types into a few families: numeric (numbers), text (strings), and collections (groups of values like lists, tuples, sets, and dictionaries).

overview.py
age = 20 # numeric name = "Alex" # text scores = [90, 85, 78] # collection print(type(age), type(name), type(scores))
▸<class 'int'> <class 'str'> <class 'list'>

02 · Numeric Types

int, float, and complex

Python has three built-in numeric types. You'll use int and float constantly — complex shows up mostly in scientific or engineering code.

🔢
int
Whole numbers
20, -7, 1000
🎯
float
Decimal numbers
3.14, -0.5
➕
complex
Real + imaginary
2+3j
🧮
bool
True / False
(a subtype of int)

Example — numeric types in action

numbers.py
whole = 42 decimal = 3.14 imaginary = 2 + 3j print(whole + decimal) print(type(imaginary))
▸45.14
▸<class 'complex'>

Note — dividing two ints with / always returns a float, even if it divides evenly. Use // for integer (floor) division.

03 · Text Type

Strings — working with text

A string (str) is a sequence of characters wrapped in single or double quotes. Strings are everywhere — names, messages, file paths, you name it.

strings.py
greeting = "Hello, World!" print(greeting.upper()) print(greeting[0]) # first character print(greeting[7:12]) # slice print(len(greeting))
▸HELLO, WORLD!
▸H
▸World
▸13

Indexing

Every character has a position, starting at 0. Use text[0] to get the first character.

Slicing

text[start:end] grabs a chunk of the string, from start up to (not including) end.

Immutable

Strings can't be changed in place — methods like .upper() return a new string instead.

f-strings

f"Hi {name}" lets you drop variables straight into a string.

04 · Collection Types

Grouping values together

Collections hold multiple values in a single variable. Python has four built-in ones, each with its own rules about order, duplicates, and whether it can change.

📋
list
Ordered, changeable
[1, 2, 3]
📦
tuple
Ordered, fixed
(1, 2, 3)
🔀
set
Unordered, unique
{1, 2, 3}
🗂️
dict
Key → value pairs
{"a": 1}

Example — a list, a tuple, a set, and a dict

collections.py
fruits = ["apple", "banana", "apple"] # list point = (4, 5) # tuple unique_ids = {101, 102, 101} # set student = {"name": "Alex", "age": 20} # dict print(fruits) print(unique_ids) print(student["name"])
▸['apple', 'banana', 'apple']
▸{101, 102}
▸Alex

list — [ ]

Ordered and changeable. Allows duplicates. The most commonly used collection.

tuple — ( )

Ordered but can't be changed after creation. Good for fixed groups like coordinates.

set — { }

Unordered and automatically removes duplicates. Great for checking membership fast.

dict — {key: value}

Stores data as labeled pairs, so you look values up by name instead of position.

05 · type()

Checking a value's type

Not sure what type something is? Use the built-in type() function any time you want to confirm what you're working with — it's one of the most useful tools for debugging as a beginner.

check_types.py
age = 20 price = 19.99 name = "Alex" fruits = ["apple", "banana"] print(type(age)) print(type(price)) print(type(name)) print(type(fruits))
▸<class 'int'>
▸<class 'float'>
▸<class 'str'>
▸<class 'list'>

🧪 Try it yourself

Create one variable of each type — int, float, str, list, tuple, set, and dict — then use type() to print each one's type.
