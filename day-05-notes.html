01 · The Big Picture

Implicit vs. explicit conversion

Type conversion means changing a value from one data type to another — like turning the text "20" into the number 20. Python handles this in two ways.

Implicit conversion happens automatically, without you asking. Explicit conversion — also called casting — is when you deliberately convert a value using a function like int() or str().

implicit.py
whole = 5 decimal = 2.5 result = whole + decimal # Python converts 5 to 5.0 for you print(result) print(type(result))
▸7.5
▸<class 'float'>

Python automatically widened the int to a float so the addition would work — no information gets lost this way. This is implicit conversion in action.

02 · Casting Functions

int(), float(), str(), and bool()

These four built-in functions let you explicitly convert a value to a different type. Each one takes whatever you give it and tries to reinterpret it as the new type.

🔢
int()
"20" → 20
3.9 → 3
🎯
float()
"3.14" → 3.14
7 → 7.0
🔤
str()
20 → "20"
True → "True"
✅
bool()
0 → False
"hi" → True

Example — converting between types explicitly

casting.py
score_text = "95" score_number = int(score_text) price = 250 price_text = str(price) pi_int = int(3.99) # chops off the decimal, doesn't round print(score_number + 5) print("Price: $" + price_text) print(pi_int)
▸100
▸Price: $250
▸3

03 · A Common Use Case

Converting input() properly

You've already seen this pattern in the last lesson — now let's understand it fully. Since input() always returns a string, you need to explicitly cast it before doing any math.

input_convert.py
age_text = input("How old are you? ") age = int(age_text) # explicit conversion print("Next year you'll be", age + 1)
▸How old are you? 20
▸Next year you'll be 21

You can also skip the middle step and convert on the same line: age = int(input("How old are you? ")). Use float() instead of int() if you're expecting a decimal, like a price or height.

04 · Collection Conversion

Converting between collections

The same idea applies to collections. list(), tuple(), and set() let you reshape one collection into another.

collections_convert.py
fruits_list = ["apple", "banana", "apple"] fruits_tuple = tuple(fruits_list) fruits_set = set(fruits_list) # duplicates removed print(fruits_tuple) print(fruits_set)
▸('apple', 'banana', 'apple')
▸{'apple', 'banana'}

list() → tuple()

Locks the values in place — useful once you're done editing a list.

list() → set()

A quick way to remove duplicates from a list.

str() → list()

list("abc") splits a string into a list of its characters: ['a','b','c'].

Order isn't guaranteed

Converting to a set means you lose the original order of items.

05 · Common Errors

When conversion fails

Not every value can be converted. If you try to turn text that isn't a valid number into an int or float, Python raises a ValueError.

value_error.py
age = int("twenty")
▸ValueError: invalid literal for int() with base 10: 'twenty'

This is why real-world programs check or handle input carefully before converting it — but for now, just remember: only convert text that actually looks like the type you're asking for.
